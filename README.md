# LQXH-cumcm-support-skills
乱崎凶华--数学建模通用辅助skills
## 1.技能/工作流 介绍
### 1.1 cumcm-idea(单skill)
提供附件与赛题.
生成整体技术路线的md文件.
点明cumcm-idea使用即可.
### 1.2 cumcm-paper-review（7个内置skill+1个总控skill）
提供论文.
对摘要，图表等论文整体内容进行审查.
点明使用cumcm-paper-review的总控skill，即可自动调用7个审查skill对论文内容进行审查，生成md文件.
### 1.3 cumcm-submission-review
提供论文，附件代码，附件数据.
对论文，附件代码，附件数据进行一致性审查，以对话的形式反馈.
点明使用cumcm-submission-review即可.
