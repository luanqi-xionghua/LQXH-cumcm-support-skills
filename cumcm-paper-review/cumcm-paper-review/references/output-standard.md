# 统一输出标准

## P0–P3 严重度定义

| 级别 | 含义 | 典型例子 |
|---|---|---|
| P0 | 致命:违规或硬伤,可能导致取消资格或评审极差 | 匿名信息泄露;摘要不能作为独立短文阅读;AI 工具被列入参考文献;正文出现身份信息 |
| P1 | 严重:明显失分点 | 假设无依据或循环论证;结果未逐项回答题目;引用与文献条目不对应;检验方法与模型类型不匹配 |
| P2 | 中等:影响评审印象 | 有量纲符号未标单位;灵敏度与稳健性混写;附录结构混乱;图表未被正文引出 |
| P3 | 轻微:润色级 | 措辞、编号、标点、格式微瑕 |

## 片段格式

骨架见 assets/fragment-template.md。硬性规则:

- 状态行三选一:`完整检查` / `受限检查(原因)` / `未完成(原因)`;`未检查(技能缺失)` 与 `未在本次范围` 只由编排器在总报告填写,片段不使用。
- 证据必须可定位:页码、章节号、行号或原文摘录;禁止"感觉""似乎偏少"这类无证据表述。
- 问题清单按严重度降序排列;修改建议要可执行,但不得整章重写。
- 无法核验事项独立成节,不得混入问题清单,也不得计入评级扣分。
- 片段语言与用户语言一致(默认中文)。

## 章节评级

| 评级 | 判据 |
|---|---|
| A | 无 P0、无 P1 |
| B | 无 P0,有 P1 但 ≤ 2 条 |
| C | 无 P0,但 P1 ≥ 3 条,或存在 P2 |
| D | 存在 P0 |

评级只描述"该章诊断结果",不是论文总分;本工作流不换算分数、不估计奖项。

## 总报告浓缩规则

- 分章诊断浓缩:每章 ≤ 8 行,只保留全部 P0/P1 与代表性 P2;细节留在片段,报告给出片段索引。
- Top 问题 = 全部 P0 + 全部 P1,按严重度、再按章节顺序排列。
- 计数与评级必须与片段一致;汇总时只允许合并去重,不允许增删问题。
